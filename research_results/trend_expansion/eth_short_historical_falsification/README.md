# ETH SHORT historical falsification V1

Implementation only; historical economic evidence pending local user execution.
[Frozen protocol and commands](../../../docs/eth-short-historical-falsification-v1.md).

This historical challenge is a falsification study of frozen hypotheses. It does not
constitute paper or live trading approval and does not establish future profitability.

Two full frozen six-configuration regions, ATR/hybrid ETHUSDT1h SHORT_ONLY, previous
published source20261007T203824Z-364120f09438. Partial2020 after1000-bar warmup,
2021/2022 complete, BASE/ADVERSE;72 backtests. No pure Donchian or parameter selection.

`lab.py eth-short-history compare` audits completed runs without simulation.
`lab.py eth-short-history publish latest` creates one unique immutable publication:
summary.csv, year_comparison.csv, strategy_comparison.csv,
base_adverse_comparison.csv, parameter_robustness.csv, trade_distribution.csv,
outlier_dependency.csv, regime_comparison.csv, falsification_scorecard.csv,
conclusions.md, sources.json, metadata.json. Allowlist/default5MB per file.

Heavy results, ledgers, equity and datasets remain local. Verdicts manual/descriptive;
no automatic score, future holdout claim, forward/OKX/paper integration or Git push.
